# Con Market guide — release notes

Astro tourist information site with Vietnamese pages at the root and localized English `/en/`, Simplified Chinese `/zh/` and Korean `/ko/` variants. The source registry contains 45 topic guides and 31 nearby place guides, as well as the home page, legal pages, and a documentary photo gallery. All language variants are generated by `scripts/localize.mjs`.

## Verification and deployment

- `pnpm install --frozen-lockfile` (using the repository's pinned package manager)
- `pnpm check`
- `pnpm run build` (Astro build followed by the localization script)
- `node --test tests/*.test.mjs`
- After verifying output and environment permissions, deploy with the Cloudflare Workers project command `pnpm run deploy` or `wrangler deploy`.

GitHub commits alone do not prove Cloudflare production deployment unless the external Cloudflare build integration is confirmed. No GitHub Actions workflow is configured in this repository at the time of this note.

## SEO and editorial behavior

- Canonical production origin: `https://conmarket.org`. The Worker provides permanent (308) HTTP-to-HTTPS and `www` host normalization for requests it receives.
- Four-way reciprocal `hreflang`; `x-default` directs visitors to the English version of the same page. Do not create a false Traditional Chinese `zh-Hant` alternate without a fully localized Traditional Chinese page.
- The privacy, terms, and cookie-setting pages remain publicly linked and readable but are tagged `noindex,follow` and excluded from the generated sitemap.
- Sitemap includes all substantive guides, nearby place pages, home pages, and the photo gallery.
- Restore and reuse factual photographs from the project archive; see `MEDIA.md` for provenance and rights notes. Do not present compiled source material as a first-hand market visit.
